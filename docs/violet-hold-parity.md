# 紫羅蘭堡大逃亡官方一致性核對

結論：**尚未與官方完全一致，不能宣稱全系列已完整還原。**

## 資料來源與範圍

核對日期：2026-10-03。來源為 [HearthSim 的官方客戶端 CardDefs 資料](https://raw.githubusercontent.com/HearthSim/hsdata/master/CardDefs.xml)，build `253932`，本次 XML SHA-256：`6d75f63414c9ea0c1edaad9e2549aae7322cc0fde0f7953748ceb9c91ac1f419`。

官方此系列共有 **164 張可收藏卡**。目前已收錄全部 164 張，包括新增的 4 張地標。先前的 160/160 是生成器先排除不支援類型後的統計，不代表官方全系列完整。

`npx tsx scripts/audit-violet.ts` 直接從原始 XML 枚舉所有可收藏卡，不先過濾卡牌類型；檢查 ID、官方中英文名稱、敘述、費用、攻擊力、生命／耐久與官方關鍵字標籤。**目前回傳零退出碼，164 張的靜態資料核對通過**。這與單元測試是不同檢查，不能只用單元測試通過宣稱完全一致。

## 本次確認並修正

- 手動效果覆寫漏掉官方關鍵字：CAP_406、JAIL_035、JAIL_311、JAIL_384 的嘲諷，以及 JAIL_719 的生命竊取。生成器現在保留官方關鍵字。
- JAIL_030 逃脫大師被額外賦予官方卡面沒有的潛行。
- JAIL_501 開鎖人應只能指定敵方手下；零剩餘法力時數值為零，不能強制變成一。
- JAIL_866 致命食譜的 +3/+3 應套用到抽出的兩個手下，而不是只有最後一張。
- JAIL_882 的亡語應抽回曾複製的法術，不能抽任意牌堆頂卡牌。
- JAIL_470 滋事者只累積該張實體在手中／牌堆期間打出的 2 法力卡，不追溯取得之前的出牌。
- 幸運幣的不同官方造型 ID 現在都能被黑掌鞭索與阿雅的效果識別。
- 卡札克斯 1 費藥水的直接傷害需要指定目標與法術傷害加成；冰凍只選敵方手下；2/2 惡魔使用官方衍生卡 CFM_621_m4，不再隨機找其他惡魔並改體質。骯髒的幸運幣傷害也套用法傷。

## 四張地標已完成

已加入地標牌型、共用七格場地、啟動／耐久／冷卻、AI 合法動作、介面啟動按鈕與手牌鎖定提示。

- 孤寂尖塔：依手牌數召喚官方惡魔衍生卡，強制攻擊隨機敵方手下。
- 城底區網路：召喚官方 2/1 野獸，其亡語實際抽牌。
- 舒拉邁特的牢獄：選牌棄掉、召喚 5/5 嘲諷；耐久耗盡釋放 8/8 舒拉邁特，於回合結束免費打出牢獄捨棄過的牌，包含戰吼及法術。
- 低警戒區：產生隨機薩滿手下；不能靠換回合解鎖，需先打出另一張牌。

地標不屬於手下，因此一般手下攻擊、傷害與清場不影響地標，也不會因耐久耗盡而獲得手下死亡的屍體。

## 仍未完成／不能證實的部分

| 缺口 | 對一致性的影響 |
| --- | --- |
| 隨機與發現卡池 | `poolCards` 只包含本專案支援的卡，官方完整卡池含大量尚未支援卡；因此可生成的結果與機率不同，也沒有完整標準／開放賽制輪替。 |
| 複雜互動 | 尚未逐項與官方客戶端比對雙方規則破壞者、開局先後順序、複製／洗回、同時死亡與觸發的所有組合。 |
| 部分動態衍生卡 | 自訂假審判、靈質等使用 VH_* 內部 ID 與自訂顯示，不能宣稱官方卡面／圖像完全相同。 |
| 官方對照測試 | 本專案測試只驗證所寫的情境；沒有可自動操作的官方客戶端或官方規則引擎作差異測試。 |

不應把這些缺口改成假卡、縮小官方統計分母，或跳過完整性檢查來取得「全部通過」。
