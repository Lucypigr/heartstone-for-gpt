## 驗證

`src/engine/cataclysm.test.ts` 覆蓋本輪各效果，包括同名手牌選擇、無合法地標目標、延遲召喚時點、傷害波間的亡語、聖盾、溢傷與雙方牌庫。完整回歸檢查與正式建置通過。

重做靜態盤點：

```sh
npx tsx scripts/audit-coverage.ts --sets=1980 > .cache/cataclysm-coverage.json
```
