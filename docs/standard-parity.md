## 可重現的缺口盤點

```sh
npx tsx scripts/audit-coverage.ts --sets=1637,1946,1952,1957,1980,1988 > .cache/standard-coverage.json
```

指令只讀取本地官方 XML 快取，不改寫卡牌資料。輸出每張原始卡的 ID、名稱、英文效果、已映射的實作 ID、缺卡狀態與卡面差異；不會先刪掉未支援的英雄卡、地標等牌型。核心卡使用現有 DBF 別名查找，避免把已收錄的同名版本直接算成缺卡。收錄不代表效果已驗證。
